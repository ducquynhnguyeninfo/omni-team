# install — put omni-team into this workspace

The framework ships inside this plugin at `${CLAUDE_PLUGIN_ROOT}/.omni-team/`. Installing copies it into the workspace, where it is committed with the project, so every teammate and every tool uses the same pinned version. Run each command yourself; never hand the user a command you can run. Arguments: `$ARGUMENTS`.

1. **Find the workspace** — `git rev-parse --show-toplevel` from the current directory. Stop and ask when:
   - it is not a git repository: offer `git init` there (the orchestrator needs git for review scopes) or another folder;
   - the root holds `.claude-plugin/marketplace.json` naming `omni-team`: that is the omni-team repository itself, which needs no install.
2. **Already installed?** If `<workspace>/.omni-team/` exists, follow the plugin's `upgrade` skill instead.
3. **Install** — `python3 "${CLAUDE_PLUGIN_ROOT}/.omni-team/install.py" --dir "<workspace>"`, adding `--tools <list>` when the user named tools (default `claude,codex`; `all` adds Gemini and a generic `AGENTS.md` pointer for Cursor, Copilot, …). Use `python` where `python3` does not exist; Python 3.8+ is required. It writes `.omni-team/`, `.claude/agents/`, `.claude/skills/`, `.codex/agents/`, `.agents/skills/` and a pointer block in `CLAUDE.md` / `AGENTS.md`. If it refuses because a same-named file was not generated by omni-team, show the user those paths and re-run with `--force` only on their yes.
4. **Toolset** — `python3 "<workspace>/.omni-team/orchestrator.py" setup`, with `--ui-probe` when the user asked for it or the project serves a browser UI (a web framework in its manifests). Each part prints ✅ or ❌ with the reason; a ❌ goes into the report, it does not undo the install.
5. **Report** — the installed version, the added/updated counts and any warning the installer printed, the toolset lines, and the next step: run `/omni-setup` once to profile the project (start a new session first if the new skills are not listed yet), then `/omni-task <request>`. Tell the user to review and commit the new files; do not commit yourself.
